# Current Mischief

`ezpanos` is my [attempt](https://pypi.org/project/ezpanos) at making PanOS automation less clumsy:
- lightweight
- scriptable
- practical
- built for people who touch more firewalls than grass

Part experiment, part utility, part refusal to keep doing things the painful way.

`F5XC_API_Arbitration` is a [Service Proxy](https://github.com/BlackPropaganda/F5XC_API_Arbitration) that extends security controls for F5XC API Keys
- Allows authorized changes to commonly modified configurations like Load Balancer Routes
- Denies unauthorized changes
- Maintains all traceability and logging
- Eventually want to implement proper identity provider support/RBAC.
